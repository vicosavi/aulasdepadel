# Aulas de Padel / Padel Lessons (demo)

Demonstração de um sistema de aulas de padel, em português e inglês (botão **PT | EN** em todas as páginas).
A padel lessons demo, in Portuguese and English (**PT | EN** switch on every page).

- `index.html`: portal de marcação de aulas / lesson booking portal. Entre como **Professor** ou **Aluno** tocando num lado da quadra (senha `demo`).
- `drills.html`: drills animados e modo aula (português).
- `drills-en.html`: animated drills and class mode (English).

Os dados ficam só no navegador de quem abre a página. Os alunos são fictícios. Não use senhas reais.
Data stays in the visitor's browser only. Students are fictional. Do not use real passwords.
